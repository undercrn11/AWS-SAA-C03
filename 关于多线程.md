# 关于多线程

以前的游戏没有多线程的设计的一个主要原因就是： 

1.多线程架构属于面向数据设计，一般软件设计属于面向对象，首先设计模式不一样，提高难度。

 2.多线程设计重点并不是让多个核心动起来，而是要设计内存布局，让cpu减少内存读取次数，增加缓存命中率，这部分内容也是属于面向数据设计。 

3.一个优秀的线程调度系统难设计，他不属于游戏顶层应用，是更基础的东西，最好的解决方案是游戏引擎提供（unity的jobSystem）

 总结： 厂商自己要以面向数据设计来开发游戏。厂商有动力选择多线程开发的前提是：有方便的多线程调度系统。

**图形处理单元上的通用计算**（英语：General-purpose computing on graphics processing units，简称**GPGPU**或GP²U），是利用处理图形任务的[图形处理器](https://zh.wikipedia.org/wiki/圖形處理器)来计算原本由[中央处理器](https://zh.wikipedia.org/wiki/中央处理器)处理的通用计算任务。这些通用计算任务通常与图形处理没有任何关系。由于现代图形处理器有强大的并行处理能力和可编程流水线，令图形处理器也可以处理非图形数据。特别是在面对[单指令流多数据流](https://zh.wikipedia.org/wiki/单指令流多数据流)（SIMD）且数据处理的运算量远大于数据调度和传输的需要时，通用图形处理器在性能上大大超越了传统的中央处理器应用程序。

PCIe (Peripheral Component Interconnect Express)是一种高速接口标准，其用于取代旧的总线标准如PCI，PCI-X。主要用于连接各种电脑设备，如显卡和固态内存（SSD）。其为CPU和其他设备提供了高速数据传输的功能。

南桥(Southbridge)和北桥(Northbridge):南桥和北桥是现代计算机主板内的组件，北桥用于作为CPU和RAM连接的桥梁，同时可用于连接PCIe。南桥和北桥相连，用于和其他I/O设备连接。如USB，声卡，PCI等等。
